# 🚀 NeetCode Solutions - Roadmap to Mastering DSA

Repository ini berisi solusi dari berbagai tantangan algoritma dan struktur data yang diambil dari [NeetCode.io](https://neetcode.io/). Sinkronisasi dilakukan secara otomatis setiap kali saya menyelesaikan soal di platform tersebut.

## 📌 Tentang Repository
Tujuan dari repository ini adalah untuk mendokumentasikan perjalanan belajar saya dalam persiapan *Technical Interview* dan memperkuat pemahaman tentang **Data Structures and Algorithms (DSA)**.

## 🛠️ Tech Stack
*   **Language:** C++
*   **Platform:** NeetCode / LeetCode
*   **Tools:** GitHub Sync

## 📈 Progress Roadmap
Solusi dikelompokkan berdasarkan kategori yang ada di NeetCode Roadmap:
- [x] Arrays & Hashing
- [x] Two Pointers
- [x] Stack
- [ ] Sliding Window
- [ ] Linked List
- [ ] Binary Search
- [ ] Trees
- [ ] Tries
- [ ] Backtracking
- [ ] Graphs
- [ ] Dynamic Programming

## 📂 Struktur Folder
Folder disusun berdasarkan nama masalah atau kategori soal. Setiap folder biasanya berisi:
- `solution.cpp`: Implementasi kode dalam C++.
- `README.md`: Penjelasan singkat atau link ke soal terkait (jika ada).
